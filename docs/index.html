Rust puro, motor async, cero excusas. La capa scriptable del mangoSuite para bajar cualquier cosa desde tu terminal o tu pipeline de CI.

2. Synopsis

Un comando, cualquier fuente

mangofetch <download|download-multiple|info|check> [URL|FILE] [FLAGS]
3. Description

Diseñado para vivir en scripts, no en pestañas de navegador

mangofetch-cli es la interfaz no interactiva del mangoSuite: sin ventanas, sin clics, solo exit codes predecibles. Corre sobre Tokio, detecta y auto-provisiona binarios externos cuando hacen falta, y habla con más de 1000 plataformas a través de mangofetch-core.

4. Features

Lo que trae de fábrica

async

Motor async sobre Tokio

Pensado para cron jobs y pipelines de CI donde bloquear un hilo no es opción.

1000+

Cobertura masiva de plataformas

YouTube, torrents, SoundCloud, Instagram y el resto vía mangofetch-core.

cross-os

Multiplataforma real

Windows 10/11, macOS, GNU/Linux, BSD. AMD64, ARM64 y ARMv7.

auto-bin

Binarios auto-provisionados

Detecta y descarga yt-dlp, ffmpeg y aria2c cuando faltan.

6. Installation

Instalación

Vía Cargo (recomendado)

cargo install mangofetch-cli

Desde el código fuente

git clone https://github.com/julesklord/mangofetch-cli.git
cd mangofetch-cli
cargo build --release
7. Examples

Uso rápido

Descargar un único URL

mangofetch download https://example.com/video

Descarga por lotes

mangofetch download-multiple links.txt

Metadatos sin descargar

mangofetch info https://example.com/video

Verificar dependencias

mangofetch check
