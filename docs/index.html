mangofetch‑cli

Fast, tropical, pure‑Rust CLI for scriptable media downloads.

Instalar con Cargo

Características

Motor asíncrono

Potenciado por Tokio; ideal para cron jobs y pipelines CI.

Más de 1000 plataformas

Descargas de YouTube, Torrents, SoundCloud, Instagram y más mediante mangofetch‑core.

Multi‑plataforma

Windows 10/11, macOS, GNU/Linux, BSD; AMD64, ARM64 y ARMv7.

Binaries auto‑provisionados

Detecta y descarga yt‑dlp, ffmpeg, aria2c cuando faltan.

Parte del mangoSuite

mangofetch‑cli es la capa no interactiva del mangoSuite:

  • mangofetch – motor core y TUI interactiva.
  • mangofetch‑cli – esta herramienta de línea de comandos.
  • mangofetch‑gui – aplicación de escritorio con egui.

Instalación

Via Cargo (recomendado)

cargo install mangofetch-cli

Desde el código fuente

git clone https://github.com/julesklord/mangofetch-cli.git
cd mangofetch-cli
cargo build --release

Uso rápido

Descargar un único URL

mangofetch download https://example.com/video

Descarga por lotes

mangofetch download-multiple links.txt

Obtener metadatos sin descargar 

mangofetch info https://example.com/video

Verificar dependencias del sistema 

mangofetch check
